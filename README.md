# មជ្ឈមណ្ឌលឧបករណ៍អប់រំ និងល្បែងសិក្សា (Educational Hub)

កម្មវិធីគេហទំព័រមជ្ឈមណ្ឌលឧបករណ៍អប់រំ និងល្បែងសិក្សាសម្រាប់ជំនួយដល់គ្រូបង្រៀន និងសិស្សានុសិស្សបឋមសិក្សា។ កម្មវិធីនេះដំណើរការនៅលើ Browser ផ្ទាល់ដោយប្រើប្រាស់តែ HTML, CSS, និង Vanilla JavaScript សុទ្ធសាធ (ដំណើរការបានដោយពុំចាំបាច់មាន Internet/Offline បាន ១០០%)។

---

## 🎨 លក្ខណៈពិសេសនៃការរចនា (UI/UX Design)
*   **រចនាបថទំនើប៖** ប្រើប្រាស់ Glassmorphism (ផ្ទៃថ្លាដូចកញ្ចក់) និងពណ៌ Gradient ស្រស់ស្អាតទាក់ទាញចិត្តកុមារ។
*   **ពុម្ពអក្សរខ្មែរ៖** ប្រើប្រាស់ពុម្ពអក្សរផ្លូវការ **Kantumruy Pro** ពី Google Fonts។
*   **ប្រព័ន្ធសំឡេងឆ្លាតវៃ៖** ប្រើប្រាស់ Web Audio API ដើម្បីបង្កើតសំឡេងចុច សំឡេងឈ្នះ/ចាញ់ ដោយពុំចាំបាច់ទាញយកឯកសារសំឡេងពីខាងក្រៅ។
*   **Confetti Effect៖** បែបផែនបាញ់ក្រដាសពណ៌អបអរសាទរពេលសិស្សលេងឈ្នះល្បែង។

## 📂 ឧបករណ៍ទាំង ២២ រួមមាន៖

### 🎮 ល្បែងសិក្សា (Games 1-10)៖
1.  **ឧបករណ៍ប្រភាគ៖** បង្ហាញនំខេក និងរបារប្រភាគអន្តរកម្ម។
2.  **បូកដកលេខរហ័ស៖** ល្បែងគណនាលេខបូកដកប្រជែងម៉ោង ៣០ វិនាទី។
3.  **មេគុណនិងចែក៖** បង្ហាញរូបភាពតំណាង និងសំណួរគុណចែកលេខ។
4.  **ផ្គូផ្គងរូបភាពនិងពាក្យខ្មែរ៖** ផ្គូផ្គងសត្វ ផ្លែឈើ និងវត្ថុប្រើប្រាស់។
5.  **ទាយម៉ោង៖** អានទ្រនិចនាឡិកា (ម៉ោង/នាទី) រួចចុចទាយ។
6.  **ស្គាល់លុយរៀលខ្មែរ៖** ស្គាល់ក្រដាសប្រាក់ បូកលុយ និងគណនាប្រាក់អាប់។
7.  **រាងធរណីមាត្រ៖** រៀនពីលក្ខណៈរាង 2D/3D និងល្បែងសំណួរទាយ។
8.  **តម្រៀបអក្សររាយប៉ាយ៖** ផ្គុំតួអក្សរ ស្រៈ និងជើងខ្មែរទៅជាពាក្យត្រឹមត្រូវ។
9.  **ញែកលេខគូនិងលេខសេស៖** ញែកលេខធ្លាក់ចុះដាក់ចូលកន្ត្រកឱ្យទាន់ពេល។
10. **ល្បែងបើកកាតចងចាំ៖** បើកកាតផ្គូផ្គងរូបភាពសត្វដូចគ្នាទាំង ៨ គូ។

### 🛠️ ឧបករណ៍ជំនួយការបង្រៀន (Tools 11-21)៖
11. **កងបង្វិលចាប់ពាក្យ៖** កង់បង្វិលចាប់ពាក្យចៃដន្យសម្រាប់សកម្មភាពក្នុងថ្នាក់។
12. **កងបង្វិលចាប់ឈ្មោះសិស្ស៖** ចាប់ឈ្មោះសិស្សឡើងឆ្លើយ (ទាញពីឃ្លាំងទិន្នន័យបាន)។
13. **រៀបសិស្សជាក្រុមចៃដន្យ៖** បែងចែកសិស្សជាក្រុមដោយស្វ័យប្រវត្ត។
14. **កម្មវិធីចាប់លេខចៃដន្យ៖** ចាប់លេខសំណាងចៃដន្យ ជាមួយបែបផែន Roll 3D។
15. **នាឡិការាប់ថយក្រោយ៖** នាឡិកាកំណត់ពេលកិច្ចការថ្នាក់រៀន ជាមួយសំឡេងរោទិ៍។
16. **ក្តារចុចពិន្ទុក្រុម៖** កត់ពិន្ទុប្រកួតប្រជែងក្នុងថ្នាក់ (គាំទ្ររហូតដល់ ៦ ក្រុម)។
17. **ល្បែងទាយពាក្យ (Hangman)៖** ទាយតួអក្សរផ្គុំជាពាក្យអង់គ្លេសអប់រំ។
18. **ក្តារខៀនឌីជីថល៖** ក្តារខៀនសម្រាប់គូរ សរសេរ និងអាចរក្សាទុកជារូបភាពបាន។
19. **បណ្ណពាក្យ (Flashcards)៖** បណ្ណអានក្រឡាប់ 3D (ខ្មែរ គណិត និងអង់គ្លេស)។
20. **ស្វែងរកគូ៖** ភ្ជាប់គូពាក្យអង់គ្លេស-ខ្មែរ គណិតវិទ្យា និងពាក្យផ្ទុយ។
21. **អានអត្ថបទជាសំឡេង៖** បម្លែងអត្ថបទទៅជាសំឡេងនិយាយ (Text-to-Speech)។

### 💾 ឃ្លាំងទិន្នន័យ (Tool 22)៖
22. **ឃ្លាំងទិន្នន័យសិស្ស៖** កត់ត្រាឈ្មោះ ភេទ ពិន្ទុ រក្សាទុកក្នុង Local Storage នាំចេញ/នាំចូលជា Excel (.xlsx) តាម SheetJS។

## 🚀 របៀបបើកដំណើរការនៅលើកុំព្យូទ័រ (Run Locally)
លោកអ្នកពុំចាំបាច់ដំឡើងកម្មវិធីអ្វីឡើយ៖
1.  ចូលទៅកាន់ថតគម្រោង `educational-hub`។
2.  ចុចពីរដង (Double Click) លើឯកសារ `index.html` ដើម្បីបើកដំណើរការកម្មវិធីភ្លាមៗនៅលើកម្មវិធីរុករក (Chrome, Edge, Safari, Firefox)។

## 🌐 របៀបរៀបចំ និង Deploy ទៅកាន់ GitHub Pages (ឥតគិតថ្លៃ)

ដើម្បីដាក់ឱ្យប្រើប្រាស់ជាសាធារណៈលើអ៊ីនធឺណិត (Deploy) តាមរយៈ **GitHub Pages** ដោយពុំចាំបាច់ដំឡើង Git៖

### វិធីសាស្ត្រងាយស្រួលបំផុត (តាមរយៈ GitHub Web Interface)៖
1.  ចូលទៅកាន់គេហទំព័រ [github.com](https://github.com) រួចចុះឈ្មោះចូលប្រើប្រាស់ (Sign In)។
2.  បង្កើត Repository ថ្មីមួយ៖
    *   ចុចលើប៊ូតុង **"New"** (ឬសញ្ញាបូក ➕ នៅជ្រុងខាងស្តាំលើ)។
    *   ដាក់ឈ្មោះ Repository (ឧទាហរណ៍៖ `educational-hub`)។
    *   ជ្រើសរើសប្រភេទជា **Public** (ចាំបាច់ណាស់សម្រាប់ប្រើប្រាស់ GitHub Pages ឥតគិតថ្លៃ)។
    *   ចុចប៊ូតុង **"Create repository"**។
3.  បញ្ចូលកូដទៅកាន់ GitHub៖
    *   នៅលើទំព័រថ្មីដែលទើបបង្កើតរួច សូមចុចលើពាក្យ **"uploading an existing file"**។
    *   អូស និងទម្លាក់ (Drag and Drop) រាល់ឯកសារ និងថតទាំងអស់នៅក្នុងថត `educational-hub` (រួមមាន `index.html`, `global.css`, `shared.js`, ព្រមទាំង Folders `games`, `tools`, `database`, `assets`) ចូលទៅក្នុងប្រអប់ទំព័រ GitHub។
    *   រង់ចាំឱ្យវា Upload ចប់សព្វគ្រប់ រួចចុចប៊ូតុង **"Commit changes"** នៅខាងក្រោម។
4.  បើកដំណើរការ GitHub Pages៖
    *   ចូលទៅកាន់ Tab **Settings** (រូបកង់ធ្មេញ) នៃ Repository របស់អ្នក។
    *   នៅ مនុយខាងឆ្វេង ផ្នែក "Code and automation" សូមចុចលើពាក្យ **Pages**។
    *   នៅក្រោមផ្នែក "Build and deployment" ត្រង់ចំណុច **Branch** សូមប្តូរពី `None` ទៅជា `main` (ឬ `master`) រួចចុចប៊ូតុង **Save**។
    *   រង់ចាំប្រហែល ១ ទៅ ២ នាទី រួច Refresh ទំព័រនោះ លោកអ្នកនឹងឃើញលីងគេហទំព័ររបស់អ្នកនៅផ្នែកខាងលើ (ឧទាហរណ៍៖ `https://ឈ្មោះគណនីរបស់អ្នក.github.io/educational-hub/`) ដែលអាចចែករំលែកទៅកាន់គ្រូបង្រៀន និងសិស្សានុសិស្សប្រើប្រាស់បានទូទាំងពិភពលោក!
